# 小红书运营新手 30 天学习计划

> 结合 Agent 辅助，从 0 到能独立运营。

---

## 核心理念

**不是"学完再开始做"，而是"边做边学，用输出倒逼输入"。**

你的优势：
- 有 Agent 帮你降低执行成本（选题、作图、发布）
- 可以把学习过程本身变成内容
- 数据反馈快，适合快速迭代

---

## 阶段一：建立认知（Day 1-7）

### 目标
理解小红书是什么、用户是谁、内容怎么被分发。

### 学习内容

| 主题 | 学习资源 | 行动任务 |
|------|---------|---------|
| 平台定位 | 小红书创作者学院（免费） | 看完"新手入门"板块 |
| 算法逻辑 | 搜索"小红书算法机制" | 整理 3 篇高赞解释，对比差异 |
| 用户画像 | 观察自己的发现页 | 记录 20 篇爆款笔记的共性 |
| 内容形式 | 对比图文/视频/直播 | 确定自己先主攻图文 |

### Agent 辅助

```bash
# 用研究脚本批量抓取某个领域的爆款
bun run .agent/tools/xhs-research.ts 职场
bun run .agent/tools/xhs-research.ts 个人成长
bun run .agent/tools/xhs-research.ts 小红书运营
```

### 本周内容输出（3-4 篇）

1. **"Day 1：我决定让 Agent 帮我运营小红书"** — 官宣+目标
2. **"研究了 50 篇爆款后，我发现了 3 个反常识规律"** — 学习笔记
3. **"小红书算法到底看什么？我翻了官方创作者学院"** — 知识总结
4. **"踩坑记录：原来标题不能超过 20 个字"** — 踩坑实录

---

## 阶段二：内容实践（Day 8-14）

### 目标
掌握选题→文案→配图→发布的完整流程，建立手感。

### 学习内容

| 主题 | 学习方法 | 行动任务 |
|------|---------|---------|
| 选题方法 | 分析竞品账号 | 找出 10 个对标账号，记录选题 |
| 标题技巧 | 拆解爆款标题 | 建立标题库（50 个） |
| 封面设计 | 分析高点击率封面 | 总结配色/排版/字体规律 |
| 文案结构 | 拆解爆款正文 | 总结 3 套常用结构 |

### Agent 辅助

- 用研究脚本每日抓取热门选题
- 用 Python 脚本批量生成配图模板
- 用发布脚本定时发布

### 本周内容输出（4-5 篇）

1. **"我的选题库是怎么建的？Agent 每天帮我抓 10 个"**
2. **"标题怎么写？我拆解了 50 个爆款，总结出 5 个公式"**
3. **"封面配色对比：哪种风格点击率更高？"**
4. **"文案结构 A/B 测试：清单体 vs 故事体"**
5. **"Week 2 复盘：发布了 7 篇，数据最好的是..."**

---

## 阶段三：数据驱动（Day 15-21）

### 目标
学会看数据、找规律、做优化。

### 学习内容

| 主题 | 学习方法 | 行动任务 |
|------|---------|---------|
| 创作者中心数据 | 每日查看数据看板 | 记录曝光/点击/互动/涨粉 |
| A/B 测试 | 控制变量发内容 | 同一选题换标题/封面测试 |
| 用户反馈 | 看评论、私信 | 总结用户高频问题/需求 |
| 迭代优化 | 基于数据调整 | 停掉低数据方向，放大高数据方向 |

### 关键指标理解

```
曝光 → 封面/标题决定（点击率）
  ↓
阅读 → 开头 3 秒决定（完播率/阅读完成率）
  ↓
互动 → 内容价值决定（点赞/收藏/评论）
  ↓
关注 → 账号价值决定（主页浏览→关注转化）
```

### 本周内容输出（3-4 篇）

1. **"Day 15：我终于看懂创作者中心的数据了"**
2. **"A/B 测试揭秘：同样的内容，换标题数据差 3 倍"**
3. **"用户评论告诉我，原来大家最想学的是..."**
4. **"Week 3 数据复盘：我做对了什么，做错了什么"**

---

## 阶段四：系统搭建（Day 22-30）

### 目标
建立可复用的工作流，实现半自动化运营。

### 学习内容

| 主题 | 学习方法 | 行动任务 |
|------|---------|---------|
| 内容日历 | 规划发布节奏 | 建立每周选题排期 |
| 模板化 | 总结可复用模板 | 标题模板×5、封面模板×3、文案结构×3 |
| 工具链 | 优化 Agent 工作流 | 选题→写作→配图→发布，一键化 |
| 长期规划 | 确定账号方向 | 基于数据，聚焦 1-2 个细分方向 |

### 本周内容输出（3-4 篇）

1. **"我的小红书运营 SOP：从选题到发布，Agent 全流程辅助"**
2. **"30 天复盘：从 0 粉丝到 XXX，我做对了什么"**
3. **"分享我的 5 个标题模板，直接套用"**
4. **"人机协作运营系统架构：人类决策，Agent 执行"**

## 学习资源推荐

### 官方（最权威）
- **小红书创作学院**（创作者中心内）— 官方规则解读
- **小红书蒲公英平台** — 了解变现模式

### 第三方（辅助理解）
- 搜索"小红书运营"，看高赞笔记本身（学习他们的写法）
- 关注 5-10 个运营类博主，拆解他们的内容

### 不推荐
- 付费课程（新手阶段不需要，先实践再决定）
- 复杂的数据分析工具（创作者中心够用）

---

## 每日时间分配建议

| 时间段 | 任务 | 时长 |
|--------|------|------|
| 早上 | 看数据、回复评论、浏览选题 | 15 分钟 |
| 中午 | 用 Agent 研究选题、生成内容 | 20 分钟 |
| 晚上 | 发布笔记、记录当日数据 | 10 分钟 |

**总计：每天 45 分钟，足够启动。**

---

## 关键原则

1. **先完成，再完美** — 第一篇数据不好是正常的，重要的是持续发
2. **数据是最好的老师** — 不要猜用户喜欢什么，让数据告诉你
3. **内容即产品** — 每篇笔记都要解决一个具体问题，给用户获得感
4. **系列感 > 单篇爆** — 连载内容更容易让人关注账号
