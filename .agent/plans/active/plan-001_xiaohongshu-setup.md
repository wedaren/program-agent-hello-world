## 目标

为小红书账号建立清晰的定位和内容体系，成为后续所有内容创作的指南针。

## 背景

这是小红书分支的第一个实践计划。基于 human-agent coexistence 框架，人类定方向，Agent 填充细节。

## 螺丝清单

### 🔩 [ ] 1. 确定账号定位
- **描述**: 明确账号赛道、目标受众、差异化价值
- **验收标准**: 
  - 赛道选择（如：职场成长 / 生活方式 / 技术分享 / 理财等）
  - 目标受众画像（年龄、性别、兴趣、痛点）
  - 账号差异化一句话定位
- **预计耗时**: 20min
- **依赖**: 无

### 🔩 [ ] 2. 建立选题库框架
- **描述**: 设计选题分类体系和储备机制
- **验收标准**:
  - 选题分类（如：干货类/故事类/测评类/互动类）
  - 首批 10 个选题储备
  - 选题来源渠道（热点追踪/用户需求/竞品分析）
- **预计耗时**: 30min
- **依赖**: 螺丝1

### 🔩 [ ] 3. 设计内容模板
- **描述**: 为每类选题设计标准化内容模板
- **验收标准**:
  - 标题公式（3-5个）
  - 正文结构模板
  - 封面图风格指南
  - 标签策略
- **预计耗时**: 30min
- **依赖**: 螺丝2

### 🔩 [ ] 4. 制定发布节奏
- **描述**: 确定发布频率、时间、内容配比
- **验收标准**:
  - 每周发布数量
  - 最佳发布时间
  - 内容类型配比（干货:故事:互动 = ?）
- **预计耗时**: 15min
- **依赖**: 螺丝2

### 🔩 [ ] 5. 建立数据追踪表
- **描述**: 设计笔记表现追踪模板
- **验收标准**:
  - 追踪指标：阅读、点赞、收藏、评论、涨粉
  - 记录模板（Markdown 或表格）
  - 复盘周期
- **预计耗时**: 15min
- **依赖**: 无
